NetBird для Home Assistant це незалежна кастомна інтеграція для моніторингу [NetBird Cloud](https://netbird.io/). Вона лише читає API та показує кількість peer-пристроїв і їхній стан. Позначка «підключено» означає зв'язок із Management Service, але **не підтверджує** доступність VPN-з'єднання між двома пристроями.

## Стан проєкту

Версія `0.1.0` це перший публічний реліз. Встановлюйте її через кастомний репозиторій HACS або вручну. Кнопка HACS відкриває цей репозиторій; вона не означає, що інтеграція є в стандартному каталозі HACS.

## Можливості

- Один обліковий запис Cloud на запис інтеграції; авторизація через персональний токен доступу (PAT).
- Спільне опитування списку peer-пристроїв кожні 60 секунд; нові пристрої з'являються без перезавантаження.
- Сенсори облікового запису: загальна кількість peer-пристроїв і кількість підключених.
- Бінарні сенсори peer-пристрою: підключення, завершення терміну входу, потреба в схваленні. Останній вимкнений за замовчуванням і створюється лише за наявності поля в API.
- Час останньої активності peer-пристрою, вимкнений за замовчуванням. Якщо коректного часу немає, значення невідоме.
- Агрегована діагностика без приватних даних та повідомлення Repairs, якщо очищення застарілого пристрою заблоковане.
- Український і англійський переклади інтерфейсу.

Підтримується лише NetBird Cloud за фіксованою адресою `https://api.netbird.io`. Самостійно розгорнуті сервери та сутності топології заплановані після `0.1.0`. Застарілі Routes, дії запису, метрики трафіку та перевірки VPN-маршруту до цього релізу не входять.

## Встановлення

Потрібні Home Assistant `2026.9.3` або новіший і Cloud PAT із доступом до облікового запису та списку peer-пристроїв. Home Assistant постачає власний Python; для розробки потрібен Python `3.14.2` або новіший.

### Через кастомний репозиторій HACS

Натисніть кнопку HACS вище або:

1. Відкрийте **HACS > Custom repositories**.
2. Додайте `https://github.com/rodion981/ha-netbird` із типом **Integration**.
3. Відкрийте **NetBird** і натисніть **Download**.
4. Перезапустіть Home Assistant.
5. Відкрийте **Налаштування > Пристрої та служби > Додати інтеграцію**, виберіть **NetBird** і введіть PAT.

Кнопка відкриває HACS; завантаження та налаштування інтеграції виконуються окремо. Якщо HACS не має доступу до репозиторію, встановіть інтеграцію вручну.

### Вручну та оновлення

Скопіюйте `custom_components/netbird` до каталогу конфігурації Home Assistant за шляхом `custom_components/netbird`. Перезапустіть Home Assistant і додайте **NetBird** через **Пристрої та служби**. Для ручного оновлення зробіть резервну копію конфігурації, замініть цей каталог файлами вибраної версії та перезапустіть Home Assistant. Для оновлення через HACS скористайтеся його звичайним механізмом і перезапустіть Home Assistant.

## Налаштування та ротація PAT

Форма перевіряє PAT через Cloud API облікового запису та peer-пристроїв. ID облікового запису запобігає дублюванню записів. Токен іншого облікового запису не замінить поточний.

Створіть новий PAT для того самого облікового запису. У записі NetBird виберіть **Reconfigure**. Home Assistant перевірить новий PAT до збереження та перезавантаження. Переконайтеся, що інтеграція працює, тоді відкличте старий PAT. HTTP 401 запускає повторну авторизацію. HTTP 403 означає нестачу дозволів; звичайний HTTP 404 не вважається доказом завершення терміну дії PAT.

## Оновлення даних і доступність

Інтеграція опитує peer-пристрої кожні 60 секунд через спільний координатор. Сенсори облікового запису рахують пристрої в останньому успішному списку; підключеними вважаються лише пристрої з явним `connected: true`. Push-оновлень і перевірки трафіку немає.

Після невдалого опитування сутності координатора стають недоступними, щоб не показувати старі дані як поточні. Peer-пристрій, відсутній в успішному списку, також стає недоступним. Якщо необов'язкове логічне поле відсутнє, відповідний бінарний сенсор недоступний, а не вимкнений. Некоректний або відсутній час останньої активності не дає значення. Поле підключення не перевіряє VPN-маршрути, DNS, ACL чи трафік між пристроями.

Після 10 послідовних **успішних** знімків без peer-пристрою інтеграція видаляє належні їй записи реєстру. Помилки не збільшують лічильник; повернення пристрою його скидає. Лічильник зберігається лише в пам'яті, тому перезавантаження може відкласти очищення. Якщо належність пристрою або сутностей неоднозначна, видалення блокується і з'являється повідомлення Repairs. Історія, вже записана Home Assistant Recorder, зберігається за його правилами.

## Приватність і діагностика

PAT зберігається в записі інтеграції Home Assistant і надсилається NetBird Cloud лише для читання API. Захищайте резервні копії та не передавайте PAT. Імена, адреси та стани peer-пристроїв можуть бути в сутностях, історії та резервних копіях Home Assistant. Інтеграція не створює окремої постійної бази peer-пристроїв. Діагностика містить лише версію, клас Cloud, результат/час/клас помилки опитування й агреговані лічильники; токенів, ID, імен, адрес і сирих відповідей немає. Перевіряйте експорт діагностики перед передаванням.

| Симптом | Що перевірити |
| --- | --- |
| Помилка авторизації | Замініть PAT того самого облікового запису через **Reconfigure** або повторну авторизацію. |
| Недостатньо дозволів | Перевірте доступ PAT до облікового запису; HTTP 403 не означає автоматично завершення терміну дії. |
| Немає з'єднання або некоректна відповідь | Перевірте доступ до `https://api.netbird.io` і стан Cloud-сервісу. |
| Peer недоступний | Перевірте останнє успішне опитування та наявність peer у NetBird Cloud. Окремі сенсори можуть бути недоступними через відсутні поля. |
| Застарілий peer залишається | Дочекайтеся 10 успішних знімків без нього; перевірте **Налаштування > Виправлення**. |
| Підключено, але трафік не проходить | Перевірте клієнти NetBird, маршрути, DNS, політики й кінцевий пристрій. |

Щоб видалити інтеграцію, видаліть її запис у **Налаштування > Пристрої та служби > NetBird**. Потім видаліть інсталяцію HACS або каталог `custom_components/netbird` та перезапустіть Home Assistant. Непотрібний PAT відкличте окремо в NetBird. Для історії Home Assistant і резервних копій діють окремі правила зберігання.

## API та обмеження

Інтеграція читає `GET /api/accounts` і `GET /api/peers` на фіксованому Cloud endpoint. Вона очікує рівно один обліковий запис і список peer-пристроїв з унікальними непорожніми ID. Необов'язкові поля можуть бути відсутніми або `null`. Некоректна обов'язкова структура відхиляє знімок; некоректний необов'язковий час стає невідомим. Загальний тайм-аут запиту 10 секунд. Після HTTP 429 або серверної помилки інтеграція чекає наступного опитування. Пагінації немає; недокументовані поля не припускаються. NetBird [зазначає, що обробка помилок API ще у стані beta](https://docs.netbird.io/api/guides/errors); коди можуть бути неоднозначними, тому звичайний HTTP 404 не означає завершення терміну PAT. Дивіться [довідник API](https://docs.netbird.io/api). Тести використовують анонімізовані дані; README не стверджує, що API перевірено на робочому обліковому записі.
